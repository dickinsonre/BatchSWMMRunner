===============================================================================

The stock EPA SWMM 5.2.4 material used by the `swmm5` browser engine and by the
bundled server executable/shared library is identified by the engine report as:

  EPA STORM WATER MANAGEMENT MODEL - VERSION 5.2 (Build 5.2.4)

The EPA SWMM source repository describes the SWMM source as released in the
public domain. That public-domain statement applies to material original to
the United States Government; it is not a blanket license for every file
distributed beside the engine. Source and artifact provenance that was not
recorded at build time remains unknown; see `client/public/engines.json`.

The native `swmm-engine/libs/` directory also contains a GNU libc dynamic
loader and shared-library objects. Those objects are separate works and are
not covered by the EPA public-domain statement. A version-matched GNU libc
notice and corresponding-source review is still required before redistributing
that native bundle. This repository makes no broader license claim for those
files.
